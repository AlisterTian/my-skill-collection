# Scope and omissions

This publication contains the research-related subset of manually installed skills. It is a curated snapshot, not a byte-for-byte backup of the author's machine.

## Installed skills not bundled

| Skills | Reason |
|---|---|
| `docx`, `pdf`, `pptx`, `xlsx` | Their installed LICENSE.txt explicitly restricts redistribution. Obtain them from an authorized source if another skill calls for them. |
| `glycoengineering`, `phylogenetics`, `primekg` | Installed license metadata says Unknown; source is omitted pending clear redistribution terms. |
| `rowan` | Installed license metadata says Proprietary; only an external service capability is referenced, no source is republished. |
| `research-paper-writing` | The installed copy has no license or sufficiently established source attribution. |
| `autoskill`, `consciousness-council`, `dhdna-profiler`, `hatch-pet`, `market-research-reports`, `pi-agent`, `ppt-master`, `usfiscaldata`, `what-if-oracle` | General-purpose, personal-workflow, presentation, or finance tools outside this research-focused snapshot. |

## Files not bundled

- Built-in `.system` skills and application/plugin caches.
- Credentials, local environment files, caches, dependency installations, and execution logs.
- ARS bakeoff execution receipts and archived run data.
- Nature skill evaluation inputs that may refer to local research attachments.
- `nature-figure/assets/figures4papers`: its installed THIRD_PARTY_NOTICES.md says redistribution permission is not established. The upstream project is https://github.com/ChenLiu-1996/figures4papers. The original figure examples and chart-atlas assets elsewhere in the skill remain included.

Some guides mention optional skills, providers, or assets that are not bundled. Install the relevant authorized provider separately or use the skill's supported alternative. A missing optional provider is not a reason to invent results or claim a tool ran.
